# ValNova Compliance Gap Assessment

## Overview

This document presents an internal compliance gap assessment for ValNova Technologies, a fictional Nigerian fintech company.

The assessment evaluates ValNova against:

- Nigeria Data Protection Act (NDPA) 2023 / GAID 2025
- PCI DSS v4.0.1
- ISO/IEC 27001:2022
- SOC 2 Trust Services Criteria

## Assessment Approach

The assessment considered:

- Production and cloud system configurations
- Policies and governance documentation
- Access management
- Third-party integrations
- Evidence from engineering and operations teams

Each finding was assigned a severity rating and mapped to remediation actions, an owner, and a target date.

## Key Findings

The assessment identified:

- 3 High-severity findings
- 4 Medium-severity findings
- 1 Low-severity finding

The report includes the detailed findings, remediation plan, ownership model, and recommended next steps.
